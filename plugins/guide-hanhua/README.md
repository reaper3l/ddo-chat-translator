# DDO 网站攻略汉化（示例插件）

抓一页英文攻略 —— 或者剪贴板里的一段英文 —— 调用本机翻译平台，生成一份
**中英对照**的 Markdown。

## 怎么用

1. 打开「设置 → 平台 / 插件」；
2. 勾上「启用本地翻译平台」，点「立即应用」；
3. 在下面的插件列表里勾上 **DDO 网站攻略汉化**（第一次启用会发一把令牌）；
4. 回到主窗口，**右键 → 插件（外部工具）**，选一个动作：
   * **汉化剪贴板里的英文**：先 Ctrl+C 复制英文，再点它；
   * **汉化一个攻略网址**：先把网址复制到剪贴板，再点它；
   * **汉化 input.txt**：把英文存成插件目录下的 `input.txt`，再点它。

结果会显示在一个窗口里，同时会在 `plugins\guide-hanhua\output\` 下存一份
`攻略_年月日_时分秒.md`。

## 它做了什么

```
插件进程  --stdin(JSON)-->  拿到 {platform.base_url, platform.token}
   |
   +-- urllib 抓网页 / 读剪贴板 / 读文件
   |
   +-- POST /v1/translate/batch  --> 本机翻译平台（一次发一批，最省钱）
   |
   +-- 写 Markdown + 打印 {"ok": true, "text": ..., "files": [...]}
```

平台会用界面里**同一套**术语表、记忆库和缓存，所以同一段攻略翻过一次，
再翻就是本地命中，不再花钱。

## 想改？直接改这个目录

* `manifest.json`：改名、加动作、换入口；
* `plugin.py`：`_gather_text()` 决定"文本从哪来"，`_compose()` 决定"输出长什么样"。

改完在设置页点「重新扫描」即可，不用重启程序。

## 注意

* 需要 Python 3（打包版跑 `.py` 插件时，用的就是系统里的 Python）。
* 抓网页只做了很轻的 HTML → 文本处理，遇到需要登录/JS 渲染的站点抓不到正文，
  那种情况请手动复制正文用「汉化剪贴板里的英文」。
* 插件只拿到"翻译"权限（`translate` / `batch`），它**没有**改你词典的权限。
