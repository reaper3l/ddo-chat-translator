# DDO 论坛构卡汇编（插件）

把 **DDO 官方论坛**（forums.ddo.com）里跟**构卡 / 游戏机制**有关的帖子抓下来，
自动认出"当前是哪个版本"，挑出最值得看的段落，调用**本机翻译平台**翻成中文，
最后生成一份中文 Markdown：

```
版本与来源清单（哪几个板块 / 帖子、抓到多少段）
机制要点汇总（Epic Destiny / Enhancement / Feat / DC / PRR … 命中次数表）
构卡正文（中英对照，按帖子分组）
术语附录（英文 → 中文对照，能读平台术语表就带上官方译名）
```

同时会写一份同名 `.json`（结构化结果，给别的程序用）。

---

## 怎么用

1. 打开「设置 → 平台 / 插件」；
2. 勾上「启用本地翻译平台」，点「立即应用」；
3. 在下面的插件列表里勾上 **DDO 论坛构卡汇编**（第一次启用会发一把令牌）；
4. 回到主窗口 → **右键 → 插件（外部工具）** → 选一个动作：

   * **汇总官方论坛构卡资料**：按 `sources.json` 里那份清单抓（最常用，直接点它）；
   * **汇总剪贴板里的论坛地址**：先把想看的帖子地址复制到剪贴板（一行一个）再点；
   * **汇总 sources.txt 里的地址**：把地址一行一个写进插件目录的 `sources.txt` 再点；
   * **离线重排（只用上次缓存）**：不联网，把上次抓到的内容重新整理一遍。

跑完会弹一个窗口显示文档正文，同时在 `plugins\ddo-forum-build\output\` 下留一份
`构卡汇编_U8x_年月日_时分秒.md` 和同名 `.json`。点一下文档里的路径就能打开。

> 跑得久是正常的：抓十几个页面 + 翻上百段，通常 1~5 分钟；界面不会卡，
> 超时（默认 10 分钟）会被宿主连子进程一起结束。

## 需要什么权限

| scope | 必须？ | 用来干嘛 |
|---|---|---|
| `translate` | **必须** | 把抓到的英文段落翻成中文 |
| `batch` | 建议 | 一次发一批，更省接口调用次数（没有它也能跑，会自动退化成一条一条翻） |
| `terms:read` | 可选 | 附录里带上平台术语表的官方译名 |

权限不够时插件**不会崩**：它会正常退出，并告诉你缺哪一项（例如"请到 设置 → 平台 / 插件
给这个插件勾上『翻译 translate』"）。同理，配额用完了会返回 429，插件会把已经翻好的部分
先写进文档，剩下的留到下次（下次会命中缓存，不重复花钱）。

插件**拿不到**你的 DeepSeek API Key —— 翻译只能走平台转发。

## 抓哪些页面（`sources.json`）

默认清单是论坛里跟构卡 / 机制最相关的几个板块目录页：

* 角色构筑与职业（`character-builds-and-classes.24`）
* 玩法与游戏系统（`gameplay-and-game-systems.55`）
* 玩家攻略 / 常见问题（`player-guides-…-faq.64`）
* 更新公告（`release-notes.7`）
* 开发者日记 / 官方讨论（`developer-diaries-and-official-discussions.9`）

板块目录页会被自动展开：插件从里面挑几个主题帖（默认每个板块 4 个）再进去抓正文。
想固定看某个帖子，就把**主题帖地址**直接写进 `sources.json`，它会被当成帖子页处理。

```json
{"sources": [
  {"url": "https://forums.ddo.com/index.php?threads/…/", "note": "某篇构卡帖"}
]}
```

* `url` 也可以写**本地 HTML 文件**的路径（相对插件目录），方便离线整理；
* `note` 只是文档里显示的名字，可省；
* 改完不用重启程序，重新点一次动作就生效。

## 它怎么做的

```
sources.json / 剪贴板 / sources.txt
        │
        ├─ 抓页面（urllib，UA 自报家门，两次抓取间隔 0.8 秒）
        │     └─ 缓存到 cache\pages\，默认 7 天：同一份内容不反复打扰论坛
        │
        ├─ 拆正文（XenForo / vBulletin 的楼中楼结构；丢掉引用块、签名、评分栏）
        │
        ├─ 认版本：扫 "U81" / "Update 81" / "Module 12"，取最大的当当前版本
        │
        ├─ 挑重点：按构卡关键词命中 + 长度打分，每个帖子最多留 12 段
        │
        ├─ POST /v1/translate/batch（一次 20 段；本地命中的不花钱）
        │     └─ 译文缓存在 cache\translate.json，重排 / 重跑不重复请求
        │
        └─ 写 output\构卡汇编_<版本>_<时间>.md + .json，再打印一行 JSON 回话
```

**可以传给插件的参数**（正常用右键菜单不用管；写脚本调 `PluginRegistry.run` 时有用）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `sources` | — | 直接给来源数组，覆盖 `sources.json` |
| `path` | `sources.txt` | `collect-file` 动作读哪个文件 |
| `output_dir` | `output\` | 文档写到哪儿 |
| `refresh` | `false` | `true` = 忽略缓存重新抓 |
| `offline` | `false` | `true` = 只用缓存，不联网 |
| `game_version` | 自动识别 | 直接指定版本号，写在文档标题上 |
| `threads_per_section` | 4 | 每个板块展开几个主题帖 |
| `max_pages` / `max_threads` | 24 / 16 | 本轮抓取的总量上限 |
| `keep_per_thread` | 12 | 每个帖子最多留几段 |
| `max_paragraphs` | 160 | 整篇文档最多翻几段 |
| `time_budget` | 480 | 翻译阶段最多花多少秒（超了就交残稿，不硬等） |

## 注意

* 需要 Python 3（打包版跑 `.py` 插件时用的是系统里的 Python）。
* 只抓**公开页面**，不改论坛任何东西；默认缓存 7 天，跑太勤也只是读缓存。
* 论坛改版、需要登录、或者要 JS 渲染的页面可能抓不到正文，那种情况退回"整页纯文本处理"
  并在文档开头写一条提示；想稳妥点就手动复制正文，用自带的示例插件翻。
* 版本号靠正文里的 `U81` 这类线索推断，认不出时会写"未知版本"，可以用 `game_version`
  自己指定。
* 原文版权归论坛原作者与 Standing Stone Games；生成的文档是给个人阅读的对照稿，
  官方译名以游戏内为准，发现更好的译法可以在界面里按 F10 纠错。
