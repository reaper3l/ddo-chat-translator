# DDO 翻译助手 v3.0.34

**DDO（龙与地下城 Online）游戏聊天实时翻译助手**

盯着 DDO 的聊天框，把外国玩家说的英文实时翻成中文；也能把你想说的中文翻成
外国玩家习惯的英文缩写。翻译错了你改一次，它记住，下次遇到同样的句子直接用你的译法。

免费、无广告、不注册。只在本机读屏幕，翻译走你自己填的接口。

## 它能做什么

- **看懂外国玩家在说什么**
  框住游戏聊天框，英文实时翻成中文。显示格式和游戏聊天框一模一样 ——
  频道、玩家名 1:1 还原，只把玩家说的话换成中文。

- **自己说话有人帮**
  中译英；还能根据最近几条聊天**推荐回复**，给出 4 条中英对照，点一下复制英文，
  回游戏粘贴就能发。常用语（马上到 / 缺人 / 复活我…）也是一键复制。

- **越用越准**
  哪句翻得不顺眼，鼠标选中按 **F10** 改成你要的说法 —— 同一句以后直接用你的译文，
  不花接口钱。游戏术语（reaper / shrine / favor…）可以加进词典固定译法，
  聊天里反复出现的新词会自动列进「待学习词」。

- **不挡游戏画面**
  暗色小窗，工具条可以收成一条只有频道小灯的窄条，还能把背景设成全透明 ——
  屏幕上只剩译文浮在游戏画面上。

- **省心**
  自动检查更新，点一下就升级，配置和学习记录都保留。
  程序只在本机读屏幕，**默认不上传你的游戏画面、聊天内容或个人信息**；
  联网只做三件事（都可以关）：检查更新、获取公共词典、以及**默认关闭**的"参与改进"。

## 下载与安装

1. 打开 [发行版页面](https://gitee.com/git55236/ddo-chat-translator/releases)，
   下载最新的 `DDO翻译助手_vX.Y.Z.zip`。
2. **解压**到一个自己有写权限的目录（例如 `D:\DDO翻译助手\`），别直接在压缩包里双击运行。
3. 双击里面的 `DDO翻译助手_vX.Y.Z.exe` 启动。
   - Windows 可能提示「**未知发布者**」，点「更多信息 → 仍要运行」就行
     （为什么没买证书见 [安全与验证说明.md](安全与验证说明.md)）。
   - 第一次打开会先弹「使用须知与免责声明」，同意后才能用。
4. 以后不用重新下载：程序会自己检查新版本。

> 想直接用源码跑：装好 Python 3.11，`pip install -r requirements.txt` 后 `python main.py`。

## 三分钟上手

1. 点工具栏的 **区域**，拖框住游戏里的聊天框（松手会立刻抓一帧给你确认）。
2. 点 **设置 → 翻译**，填 DeepSeek API Key。没有 Key 就先用 `mymemory`（免费，质量一般）。
3. 点 **▶ 监听**，切回游戏。
4. 看到翻错的行，用鼠标选中它按 **F10**，改成正确的中文 —— 从此同样的句子按你的译法来。

拿不准环境有没有问题，可以先自检：`python tools\doctor.py --api`

## 快捷键

| 键 | 作用 |
| --- | --- |
| **F8** | 开始 / 停止监听 |
| **F9** | 把剪贴板里的中文翻成英文 |
| **F10** | 纠正选中的那条翻译 |
| **F5** | 测试识别（抓一帧，显示画面和识别结果） |

## 常见问题

**监听时游戏卡顿？**
默认已经做过优化（画面没变就跳过 OCR、只识别变化的那几行、程序优先级低于游戏）。
还卡就打开 **设置 → 监控**，把 **OCR 线程数改成 1**，截图间隔再调大一点。
另外游戏请用**窗口化 / 无边框窗口**模式：独占全屏下截图会强制切换显示模式，更容易卡。

**翻译显示的还是英文原文？**
说明接口没调通。看状态栏的红色提示，没填 Key / Key 无效 / 余额不足 / 超时都会写明。
填了 Key 还失败，跑 `python tools\doctor.py --api` 定位。

**一直没有输出？**
① 没点「监听」；② 区域没框对（点「测试」看识别结果）；③ 频道被关掉了（设置 → 频道）；
④ OCR 模型第一次加载要几秒，状态栏会提示。

**框选的位置和实际抓到的画面不一致？**
这是 Windows 显示缩放（DPI）引起的，程序现在会自动校正，状态栏会写
「截图坐标已自动校正 x0.800」这类提示。如果你的机器上还是偏：
① 点 **测试**，预览图顶部会列出屏幕尺寸 / DPI / 缩放比；
② 跑 `python tools\capture_probe.py`，它会存一张 `data\probe_overlay.png` ——
红框是你框的位置、黄框是实际截取的位置，哪个套住聊天框一眼就能看出来；
③ 还不行，把 `data\config.json` 里的 `dpi_mode` 改成 `"legacy"` 再试。

**翻译质量想再好一点？**
按见效快慢：**F10 纠错**（立刻生效）→ **词典**里补术语 → 想调语气和长短，
见 [使用说明.md](使用说明.md) 的「自我学习」一节。

**费用大概多少？**
DeepSeek 每条约几分钱到几毛钱（看长度）；术语命中和整句记忆不花钱。
不想花钱就把引擎切到 `mymemory`（免费在线，质量一般）或 `offline`（只查词典）。

**数据在哪？怎么备份？**
都在程序目录的 `data\` 里：`config.json`（设置，含你的 Key）、`memory.json`（学习成果）、
`cache.json`（翻译缓存）、`logs\app.log`（日志）。把整个 `data\` 拷走就是完整备份；
换电脑时把 `data\` 放进新目录，设置和学习记录都跟着过去。

## 最近更新

* **v3.0.34** 新手教学改成**首次使用引导**：第一次打开程序就自动弹出，一步一个功能
  （框选、填 API Key、颜色字体、纠错、过滤某人、中英互译、词典学习），**目标以外压暗**、
  要讲的地方圈出来，7 步走完即可（看完/跳过以后不再自动弹，右键菜单随时能重看）。
* **v3.0.33** 更省资源、更省心：**抓屏改用 DXGI**（实测每次 6.4ms → 0.45ms，没装也能
  自动退回）；一屏多条合并请求之后**又修掉"重建术语表把整份翻译缓存清空"**的白花钱问题
  （现在加词/纠错/公共词典更新都不再作废缓存）；**学习全部自动**（高频词组自己收，
  关程序前也补一次）；新增**自动过滤某个人说话**（右键他的一句话即可，比如过滤自己）；
  对话框按钮不会再被挤出窗口（界面缩放 1.1 + 高 DPI 时"纠正界面没有确认按钮"就是这个）；
  换显示器后老框选区域跑到屏幕外会直接提醒你重框；右键菜单新增**「演示一下」**。
* **v3.0.32** 更省接口：**一屏同时来几条新消息时合并成一次请求**（默认一批 3 条，
  模型没按格式回来自动逐条重试）；新增**高频短语挖掘**（词典窗口 →「挖掘高频短语…」：
  把反复出现的词组收进术语表，短句能整句本地翻、不调接口）；顺手修掉"每加一个词
  就把翻译缓存整份作废、白调接口"的老问题；纠错窗口的英文原文现在可以改，
  还能只把**一个词**存成术语。
* **v3.0.31** 修好"同一条消息显示两遍"（同一个人的名字被识别花就会被当成另一个人）；
  「参与改进」现在会在启动时问一次，同意后**关闭程序时自动上传**（可在窗口里改成只手动发，
  使用须知升到第 3 版、会再确认一次）；词典源支持玩家自己做（窗口里「自己做词典源…」
  有格式说明和模板）；设置页窗口拉窄时按钮不再被裁掉。
* **v3.0.30** 公共词典现在能像订阅列表一样自己加源：官方源内置（签名校验），
  你还能加**本地文件**（自己整理的术语表，改完立刻生效）或**网地址**（别人分享的
  JSON，默认不加、加了才生效）；所有源都只做加法，同名不覆盖官方词，更覆盖不了
  你自己改过的译法。另外：检查更新多了一个 GitHub 备用源（Gitee 打不开也能升级）；
  新增「参与改进」（默认关闭，把你确认过的术语匿名汇总，用来改进公共词典）；
  状态栏不再显示引擎名（腾出空间）。
* **v3.0.29** 监听时游戏更流畅：修掉 OCR 把窄条放大十几倍的问题（整帧快了约 4 倍，
  只识别变化那几行从 1 秒降到 20 毫秒）；聊天框半透明、背后景物忽明忽暗时识别更稳；
  中英互译翻完自动清空、直接打下一段。
* **v3.0.28** 新增「一键反馈」（右击窗口 → 反馈问题，自动带上日志和翻译记录、
  API Key 自动隐藏）；修好词典里点「新增/覆盖」卡死。
* **v3.0.27** 修好聊天框背景半透明导致的重复识别和误判。
